# Railway template (maintainer)

The [public Railway template](https://railway.com/deploy/youtube-transcript-mcp) is owned by Federico Scandolara's Projects. Edit it in the [Railway template editor](https://railway.com/workspace/templates/ccbf0f4a-123e-48fb-b516-f98b8d1ea4fb). Railway's old `railway.json` config format is [deprecated for new services](https://docs.railway.com/infrastructure-as-code); the template itself holds the service configuration.

1. Keep the template's source at `https://github.com/scandolo/youtube-transcript-mcp` on `main` and use the public [icon](../assets/icon.svg).
2. Keep **HTTP public networking** on port 8080 with a generated Railway domain, a volume at `/data`, and the healthcheck path `/healthz`. Railway detects the Dockerfile, which runs the server on Railway’s assigned `PORT`.
3. Start with **no required template variables**. A deployer cannot create the GitHub OAuth app until Railway assigns a domain. The server stays in safe setup mode until the deployer adds `YTM_ALLOWED_USERS`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `WEBSHARE_PROXY_USERNAME`, and `WEBSHARE_PROXY_PASSWORD` in Railway Variables. GitHub OAuth is the Railway default. Do not set `YTM_BASE_URL`, `YTM_HOST`, `YTM_PORT`, `YTM_TRANSPORT`, or `FASTMCP_HOME` in the template; Railway supplies the domain and port and the server detects the mounted volume.
4. Describe optional `YOUTUBE_API_KEY` and `GROQ_API_KEY` in the README, not as required deployment fields. The former enables reliable cloud metadata/search; the latter enables the Whisper fallback. Explain the GitHub OAuth app callback as `https://<domain>/auth/callback` and the need to add its ID and secret after deployment.
5. After template changes, apply the staged changes in Railway's architecture editor and update the public listing. Deploy a fresh copy with a test GitHub account and Residential proxy. Confirm `/healthz`, OAuth login, `health()` reporting persisted state, `youtube_video_info`, and `youtube_transcript` on a captioned video. The personal Railway workspace currently has an unpaid subscription, so a fresh paid deployment has not been verified there.

The first deployment serves only `/healthz` with `setup_required` until its domain, OAuth app, and required secrets are filled in. `/mcp` returns 503 during setup. This sequence is inherent to GitHub’s exact callback URL requirement; describe it clearly in the template overview.
